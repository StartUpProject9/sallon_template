Premium Next.js Template

Aurore Luxe Salon

1. Getting Started

Welcome to Aurore Luxe Salon! This premium template is built with Next.js 15, Tailwind CSS 4, and TypeScript. To get started, follow these simple steps:

npm install
npm run dev

Your site will be live at http://localhost:3000.

2. Customization Guide

The template is designed for easy white-labeling. All key settings are centralized:

  • Text & Data: Modify /src/data/index.ts to change services, pricing, and team members.
  • Branding: Update /src/app/globals.css to change the primary gold color and background tokens.
  • Images: All assets are located in /public/images/. Simply replace them with your own high-resolution photos.

3. Multi-Step Booking

The booking system is built with a custom state machine. You can find the logic in /src/app/booking/page.tsx. It handles service selection, stylist assignment, and time slot generation automatically.

4. Deployment

We recommend deploying to Vercel for the best performance. Simply connect your GitHub repository and Vercel will handle the rest.
